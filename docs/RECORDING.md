# Запись кликов: как научить бота делать то же, что ты

У P2P и биржи CryptoBot нет публичного API, у P2P xRocket тоже. Чтобы бот мог делать что-то сам, сначала
нужно увидеть, как это делает человек: какие экраны показывает бот, какие кнопки нажимаются, какие запросы
мини-приложение шлёт на сервер. Для этого два рекордера:

| Что записываем | Чем | Пример |
|---|---|---|
| Диалог с ботом в чате: меню, кнопки, ввод цены | `record_chat.py` | P2P CryptoBot: «Объявления → объявление → Цена» |
| Мини-приложение (окно поверх чата) | `record_webapp.py` | «Биржа» и «Кошелёк» CryptoBot, приложения xRocket |

Подсказка: если у кнопки в Telegram есть значок окошка в углу (как у «Кошелёк», «Обмен», «Биржа» в меню
CryptoBot), это мини-приложение и его пишет `record_webapp.py`. Кнопки без значка (например, «P2P») работают
в чате, их пишет `record_chat.py`.

> ⚠️ Запись идёт с настоящего аккаунта. Заявки, объявления и переводы делаются по-настоящему.
> Используй маленькие суммы и цены далеко от рынка, чтобы ничего не исполнилось.

## Подготовка (один раз)

1. `install.bat` поставит библиотеки и создаст `config.py`. Впиши в него `API_ID` и `API_HASH` (их можно взять
   из `config.py` старого бота).
2. Войди в аккаунт: `python qr_login.py test` для тестового или `python qr_login.py trader` для основного.

## Запись диалога с ботом: `record_chat.py`

```bash
python record_chat.py trader cryptobot
```

Нажимай кнопки в Telegram как обычно, на телефоне или на компьютере. Все экраны бота появятся в консоли
с номерами кнопок. Закончить: `q` и Enter или Ctrl+C.

Есть интерактивный режим, в котором кнопки нажимаются прямо из консоли:

```bash
python record_chat.py test cryptobot -i
```

| Ввод | Что делает |
|---|---|
| `3` | нажать кнопку [3] на последнем экране бота |
| `3@4567` | нажать кнопку [3] на сообщении #4567 |
| `/p2p` | отправить команду |
| `45.68` | отправить текст (например, новую цену) |
| `> 100` | отправить текст «100», а не нажать кнопку [100] |
| `!s` | показать текущий экран |
| `!q` | закончить |

Интерактивный режим лучше обычного тем, что в записи остаются точные нажатия и всплывающие ответы бота
(«Цена обновлена», «Слишком часто»). С телефона их не видно.

Для запуска без человека (так разработчик пробует сценарии через Remote Control):

```bash
python record_chat.py test cryptobot -c /p2p -c 3 --duration 15
```

## Запись мини-приложения: `record_webapp.py`

```bash
python record_webapp.py test cryptobot --button Биржа --label birzha
```

Откроется окно Edge с мини-приложением, вход уже выполнен под твоим аккаунтом. Кнопки Telegram (большая кнопка
внизу, «‹ Назад» вверху, всплывающие окна) нарисованы поверх страницы, надпись «● запись» вверху значит, что запись
идёт. Пользуйся приложением как в Telegram. Закончить: закрой окно или напиши `q` и Enter в консоли.

| Как открыть | Команда |
|---|---|
| Кнопка в меню бота | `--button Биржа` |
| Главное приложение бота | `--main` |
| Кнопка меню слева от поля ввода | `--menu` |
| `t.me/<бот>/<имя>` | `--app имя` |
| Любая ссылка на мини-приложение (`t.me/…?startapp=…`) | `--url ссылка` |
| Не знаю — покажи варианты | без параметра |

Если кнопки нет в последних сообщениях бота, рекордер сам отправит боту `/start`, чтобы появилось меню
(отключается параметром `--no-start`). Если приложение спросит «Вы уверены?» стандартным окном браузера,
вопрос появится в консоли: `y` — да, `n` — нет.

## Что попадает в запись

Записи лежат в `recordings/<время>_<chat|webapp>_<бот>_<подпись>/`:

- `chat.txt` или `summary.txt` — читать глазами: экраны, клики, запросы с ответами по порядку, список адресов API;
- `events.jsonl` — всё по порядку, для разбора;
- `assets/` — страницы и скрипты мини-приложения: по ним видно все запросы, которые приложение умеет делать.

**Что скрыто:** вход в мини-приложение (initData), cookies, токены и ключи API, пароли и PIN-коды из полей
ввода, значения из хранилищ приложения, номера карт и телефонов в текстах. Вместо них стоит `***`.

**Что остаётся:** балансы, цены, объёмы, заявки и их номера, ники. Без этого не понять, как работает приложение.
Записи не попадают в git (`recordings/` в `.gitignore`), передавай их только разработчику.

## Что записать в первую очередь

**CryptoBot, биржа** (`--button Биржа`):
1. открыть пару (например, TON/USDT) и посмотреть стакан;
2. поставить маленькую лимитную заявку далеко от рынка;
3. поменять у неё цену, если приложение так умеет;
4. отменить заявку;
5. посмотреть свои заявки и историю.

**CryptoBot, P2P** (`record_chat.py trader cryptobot -i`, основной аккаунт):
1. создать объявление (покупка и продажа);
2. поменять цену, объём и лимиты;
3. включить и выключить объявление;
4. удалить объявление.

Смена цены у нас уже записана в старом проекте, остальное нужно записать.

**xRocket** (`record_chat.py test xrocket -i`, затем `record_webapp.py test xrocket`):
1. найти, где у xRocket P2P — в чате или в мини-приложении;
2. открыть стакан;
3. создать объявление, поменять цену, отменить.

Для биржи xRocket запись не нужна: у неё официальный API.

## Как передать запись

Если твой ПК подключён через Remote Control, разработчик возьмёт папку сам. Иначе заархивируй папку из
`recordings/` и пришли архив.
