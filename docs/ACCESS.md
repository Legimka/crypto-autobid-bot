# Какие доступы дать разработчику

Разработка идёт в облачной сессии Claude Code. Облако не может зайти в Telegram, поэтому всё, что связано
с аккаунтами Telegram, выполняется на твоём компьютере. В облако попадают только код, тестовые ключи и записи,
в которых секреты уже скрыты.

## 1. GitHub

Репозиторий `Legimka/crypto-autobid-bot`, приватный. Сессия разработчика работает только с подключёнными к ней
репозиториями и сама создать новый не может. Поэтому пустой репозиторий (без README) создаёшь ты, а код в него
заливает разработчик.

## 2. Сеть облачного окружения

Меню окружения в заголовке сессии → **Edit** → **Network access** → **Allowed domains**. Галочку «Allow package
managers» оставь. Добавь:

| Домен | Зачем |
|---|---|
| `docs.xrocket.exchange` | документация биржи xRocket |
| `exchange.api.testnet.xrocket.exchange` | REST API тестовой биржи xRocket |
| `exchange.app-api.testnet.xrocket.exchange` | WebSocket тестовой биржи xRocket |
| `core.telegram.org` | описание протокола мини-приложений Telegram |

Боевые адреса бирж и сам Telegram добавлять не нужно. Telegram из облака работать не будет в любом случае:
аккаунты подключаются по протоколу MTProto, а облако выпускает наружу только HTTPS.

## 3. Тестовый токен xRocket

1. В Telegram открой `@xrocket_testnet_bot` → Menu → Settings → Exchange settings → API token и сгенерируй токен.
2. Тестовые монеты бесплатно даёт `@testgiver_ton_bot`.
3. В настройках окружения положи токен в **Network secrets** (или в переменную окружения) под именем
   `XROCKET_TESTNET_TOKEN`. Её подхватит новая сессия. В чат токен не присылай.

> ⚠️ Токен xRocket даёт **полный доступ к аккаунту, включая вывод средств**, а урезать его права нельзя.
> Поэтому разработчику — только testnet-токен. Боевой токен хранится только на твоём сервере.

## 4. Твой компьютер (Remote Control)

Так разработчик сможет сам запускать скрипты с тестовым аккаунтом.

1. Поставь Python 3.10+ (python.org, галочка «Add Python to PATH») и Git.
2. Склонируй репозиторий в отдельную папку, не в домашнюю, и запусти `install.bat`.
3. В Claude Desktop: **Settings → Claude Code → Remote Control** → добавь эту папку. Другой вариант: в терминале
   в этой папке запусти `claude remote-control`.
4. Напиши разработчику. Команды будут выполняться на твоём ПК, через твою сеть.

Если так делать не хочешь, запускай скрипты сам и присылай их вывод и папки из `recordings/`.

## 5. Тестовый аккаунт Telegram

- Вход по QR на твоём ПК: `python qr_login.py test`. Файл `sessions/test.session` остаётся у тебя.
- Положи на аккаунт 5–10 USDT в CryptoBot и в xRocket. Этого хватит на маленькие биржевые заявки по цене далеко
  от рынка: они не исполнятся, а создание и отмену можно проверить.
- С тестового аккаунта можно читать стаканы P2P и биржи и ходить по меню ботов.
- Создавать P2P-объявления с него, скорее всего, не выйдет: у xRocket новым аккаунтам запрещены объявления на
  покупку. Эти действия ты записываешь рекордером на основном аккаунте (см. [RECORDING.md](RECORDING.md)).

## Чего не давать

- `.session` основного аккаунта. Вход основного аккаунта держи вне папки, подключённой к Remote Control:
  `SESSIONS_DIR = r"C:\tg-sessions"` в `config.py`.
- Боевые токены бирж, облачный пароль (2FA), сид-фразы.
